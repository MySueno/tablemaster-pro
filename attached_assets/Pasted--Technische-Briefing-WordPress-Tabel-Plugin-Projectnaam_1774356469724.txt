# Technische Briefing: WordPress Tabel Plugin

**Projectnaam:** TableMaster Pro  
**Versie:** 1.0  
**Datum:** 24 maart 2026  
**Status:** Draft voor ontwikkeling

-----

## 1. Projectoverzicht

### 1.1 Doelstelling

Ontwikkel een WordPress plugin waarmee beheerders eenvoudig krachtige, interactieve tabellen kunnen aanmaken en publiceren via een shortcode of Gutenberg block. De tabellen ondersteunen groepering tot 3 niveaus diep, zijn volledig responsief, en bieden eindgebruikers sorteer- en filtermogelijkheden.

### 1.2 Geïnspireerde voorbeelden (zie bijlagen)

- **Bijlage 1:** Tabel met groene kopteksten, gegroepeerde rijen per bedrijf (Adobe, Apple, Cisco), met kolommen: Last Name, First Name, Company, Country, Birthday. Paginering onderaan (10 per pagina), zoekbalk rechtsboven.
- **Bijlage 2:** Tabel met rode kopteksten en sectiegroepen voor medische/farmaceutische categorieën (Massage, Matties Injectin, Curettage), inclusief subcategorieën en indicaties.

### 1.3 Doelgroepen

- **WordPress beheerder (admin):** Maakt en beheert tabellen via een intuïtief dashboard.
- **Website bezoeker:** Bekijkt, filtert en sorteert tabellen op de frontend.

## 2. Functionele Vereisten

### 2.1 Tabelbeheer (Admin)

#### Meerdere tabellen

- Onbeperkt aantal tabellen aanmaken, bewerken en verwijderen.
- Overzichtspagina (tabellenlijst) met naam, shortcode, datum aangemaakt, en snelle acties (bewerken, dupliceren, verwijderen, preview).
- Elke tabel krijgt een unieke shortcode: `[tablemaster id="5"]`

#### Rijen & kolommen

- Onbeperkt aantal kolommen instellen per tabel.
- Per kolom configureerbaar:
  - **Label** (weergavenaam)
  - **Type:** tekst, getal, datum, link, afbeelding, HTML
  - **Breedte** (vast px of % of automatisch)
  - **Uitlijning:** links, midden, rechts
  - **Sorteerbaar:** ja/nee
  - **Filterbaar:** ja/nee
  - **Verborgen op mobiel:** ja/nee
- Kolommen herordenen via drag-and-drop.

#### Rijen

- Onbeperkt aantal rijen.
- Rijen kunnen worden aangemaakt als:
1. **Gewone datarij**
1. **Groepskoptekst (niveau 1)** — e.g. “Adobe”
1. **Subgroepskoptekst (niveau 2)** — e.g. “Massage”
1. **Subsubgroepskoptekst (niveau 3)** — e.g. “Indicatie”
- Groepsrijen zijn visueel onderscheidend en kunnen ingeklapt/uitgeklapt worden.
- Rijen herordenen via drag-and-drop in de beheerdersinterface.

#### Tekstopmaak per cel

- Tekst in **vet** zetten (bold).
- Hyperlinks toevoegen aan tekst of als klikbare URL.
- Inline HTML toegestaan (voor gevorderde gebruikers, optioneel in te schakelen per tabel).

### 2.2 Weergave-instellingen (Admin)

#### Kleurenbeheer

Per tabel instelbaar via een kleurpicker:

- **Koptekstachtergrond** (header row background)
- **Kopteksttekstkleur**
- **Groepskoptekst niveau 1** achtergrond + tekstkleur
- **Groepskoptekst niveau 2** achtergrond + tekstkleur
- **Groepskoptekst niveau 3** achtergrond + tekstkleur
- **Rij-achtergrond (oneven)**
- **Rij-achtergrond (even)** — voor zebra-striping
- **Hover-kleur rij**
- **Randkleur**
- **Accentkleur** (voor sorteerpijltjes, actieve filters, etc.)

Standaard kleurthema’s (presets) beschikbaar: groen, rood, blauw, grijs + “custom”.

#### Typografie

- De plugin erft automatisch het lettertype van het actieve WordPress thema via CSS inheritance (`font-family: inherit`).
- Geen extra lettertypekeuze nodig — dit is het correcte gedrag voor thema-integratie.

#### Tabelopties

- **Zoekbalk:** aan/uit, positie (links/rechts/boven/onder)
- **Paginering:** aan/uit, standaard items per pagina (5, 10, 25, 50, 100, alle)
- **Items-per-pagina selector:** aan/uit
- **Tabelcaption/titel boven tabel:** optioneel
- **Exportknoppen:** optioneel (CSV, Excel, Print) — als uitbreidingsmodule
- **Inklapbare groepen:** aan/uit
- **Sortering bij laden:** instellen welke kolom standaard gesorteerd is en in welke richting

### 2.3 Filteropties (Frontend)

#### Globale zoekbalk

- Zoekt over alle kolommen tegelijk (debounced, 300ms vertraging).
- Gegroepeerde rijen blijven zichtbaar als kind-rijen overeenkomen.

#### Kolomfilters (optioneel per tabel)

- Dropdownfilter per kolom (gebaseerd op unieke waarden).
- Datumbereikfilter voor datumkolommen.
- Tekstzoekveld per kolom.

#### Sortering

- Klik op kolomkoptekst om oplopend/aflopend te sorteren.
- Visuele indicator (pijltje) toont huidige sorteerrichting.
- Groepsstructuur blijft intact bij sortering binnen groepen.

### 2.4 Responsiviteit

#### Breakpoints

- **Desktop (>1024px):** Volledige tabel zichtbaar.
- **Tablet (768–1024px):** Eventueel minder prominente kolommen verbergen.
- **Mobiel (<768px):**
  - Horizontaal scrollen (scroll-container met touch-support), OF
  - Kaartweergave (card view): elke rij wordt een kaart met label–waarde paren.
  - Per tabel instelbaar welke modus gebruikt wordt op mobiel.

#### Mobiele kolominstellingen

- Per kolom aan te geven: “Verberg op mobiel” checkbox.
- Prioriteitsvolgorde instellen voor kaartweergave.

### 2.5 WPML-ondersteuning

#### Vertalingen

- Volledige compatibiliteit met **WPML (WordPress Multilingual Plugin)**.
- Alle tekstvelden (kolomlabels, celinhoud, groepstitels, captiontext) zijn vertaalbaar via de WPML String Translation editor.
- Tabelconfiguratie (structuur, kleuren) wordt gedeeld tussen talen; alleen de tekstinhoud is taalspecifiek.
- Optioneel: “Tabel dupliceren per taal” voor volledige scheiding.
- Plugin registreert strings bij activatie zodat ze direct zichtbaar zijn in WPML’s vertaalbeheer.

### 3.2 Database Structuur

|Kolom       |Type              |Omschrijving                      |
|------------|------------------|----------------------------------|
|`id`        |INT AUTO_INCREMENT|Primaire sleutel                  |
|`name`      |VARCHAR(255)      |Naam van de tabel (admin gebruik) |
|`slug`      |VARCHAR(255)      |Unieke slug                       |
|`settings`  |LONGTEXT (JSON)   |Kleur, paginering, weergave-opties|

|`updated_at`|DATETIME          |Laatste wijziging                 |

|Kolom        |Type              |Omschrijving                          |
|-------------|------------------|--------------------------------------|
|`id`         |INT AUTO_INCREMENT|Primaire sleutel                      |
|`table_id`   |INT               |Foreign key naar tables               |
|`label`      |VARCHAR(255)      |Kolomnaam                             |
|`type`       |VARCHAR(50)       |text, number, date, link, image, html |
|`order_index`|INT               |Volgorde                              |
|`settings`   |TEXT (JSON)       |Breedte, uitlijning, sorteerbaar, etc.|

#### Tabel: `wp_tablemaster_rows`

|Kolom         |Type              |Omschrijving                           |
|--------------|------------------|---------------------------------------|
|`id`          |INT AUTO_INCREMENT|Primaire sleutel                       |
|`table_id`    |INT               |Foreign key naar tables                |
|`parent_id`   |INT NULL          |Groepshiërarchie (NULL = root)         |
|`row_type`    |ENUM              |‘data’, ‘group_1’, ‘group_2’, ‘group_3’|

|Kolom      |Type              |Omschrijving                         |
|-----------|------------------|-------------------------------------|
|`id`       |INT AUTO_INCREMENT|Primaire sleutel                     |
|`row_id`   |INT               |Foreign key naar rows                |
|`column_id`|INT               |Foreign key naar columns             |
|`content`  |LONGTEXT          |Celinhoud (HTML toegestaan)          |
|`lang`     |VARCHAR(10)       |Taalcode voor WPML (‘nl’, ‘en’, etc.)|

### 3.3 Frontend JavaScript

**Geen zware libraries vereist voor basisfunctionaliteit.** Gebruik Vanilla JS voor:

- Sortering (client-side voor kleine datasets, server-side AJAX voor grote)
- Filtering/zoeken (debounced input)
- Paginering
- Inklapbare groepen (toggle animatie via CSS transitions)

**Optioneel voor grote datasets (>500 rijen):** Server-side verwerking via WordPress AJAX (`wp_ajax` / `wp_ajax_nopriv`).

### 3.4 Admin Builder UI

Gebruik **Vue.js 3** (lightweight, ~34KB gzip) als frontend framework voor de beheerdersinterface:

- Reactieve drag-and-drop kolom/rij-ordening
- Live preview van kleurselectie
- Inline celbewerking
- Formuliervalidatie

Alternatief: React (indien het WordPress thema/ecosysteem dit vereist, aangezien WordPress zelf React gebruikt voor Gutenberg).

### 3.5 Gutenberg Block

Naast shortcode ook een Gutenberg block beschikbaar:

- Blok toont een dropdown om een bestaande tabel te selecteren.
- Live preview van de tabel in de editor.
- Knop “Tabel bewerken” opent de tabel in de TableMaster editor.

### 3.6 WordPress Requirements

|Vereiste        |Minimum               |
|----------------|----------------------|
|WordPress versie|5.8+                  |
|PHP versie      |7.4+ (aanbevolen 8.0+)|
|MySQL versie    |5.7+                  |
|WPML (optioneel)|4.0+                  |

### 3.7 Performance

- CSS voor kleuren wordt dynamisch gegenereerd en gecached als inline `<style>` tag (of via transient als extern bestand).
- Frontend JS en CSS worden alleen geladen op pagina’s waar een TableMaster tabel aanwezig is (`wp_enqueue_scripts` conditioneel).
- Queries geoptimaliseerd met prepared statements en joins; resultaten gecached via WordPress transients (invalidatie bij tabelwijziging).

## 4. Beheerdersinterface (UX)

### 4.1 Admin Menupagina’s

```
WordPress Admin Menu:
└── TableMaster
    ├── Alle Tabellen          (overzicht + beheer)
    ├── Nieuwe Tabel           (aanmaken)
    └── Instellingen           (globale plugin-instellingen)
```

### 4.2 Tabeleditor Lay-out

De tabeleditor bestaat uit twee panelen:

**Linker paneel: Tabelstructuur**

- Kolommenbeheer (toevoegen, herordenen, instellingen per kolom)
- Rijenbeheer met hiërarchische boomstructuur
- Drag-and-drop voor rij/kolom volgorde
- Knop “+ Rij toevoegen”, “+ Groep toevoegen (niveau X)”
- Inline celbewerking — klik op cel om te bewerken

**Rechter paneel: Tabelinstellingen**

- Tabbladen: Kleuren | Weergave | Filteropties | Geavanceerd
- Kleurpickers per element (met hex-input + kleurkiezer)
- Kleurpresets (1-klik thema’s)
- Live preview onderaan/naast het paneel

### 4.3 Live Preview

- Kleine live-preview widget toont hoe de tabel eruitziet met de huidige kleurinstellingen.
- Preview update real-time bij kleurwijzigingen.
- Knop “Bekijk op website” opent frontend preview in nieuw tabblad.

### 4.4 Shortcode Weergave

Na opslaan zichtbaar:

```
Shortcode: [tablemaster id="7"]   [Kopiëren]
```

## 6. WPML Integratie Details

### 6.1 Werking

1. Plugin registreert alle vertaalbare strings via `icl_register_string()` bij opslaan van een tabel.
1. String-domeinnaam: `tablemaster-pro`
1. Cel-inhoud per taal opgeslagen in `wp_tablemaster_cells.lang` kolom.
1. Bij frontend rendering: huidig WPML taal-slug ophalen via `ICL_LANGUAGE_CODE` en correcte celinhoud laden.

### 6.2 Wat is vertaalbaar

|Element         |Vertaalbaar    |
|----------------|---------------|
|Cel-inhoud      |✅ Ja           |
|Kolomlabels     |✅ Ja           |
|Groepstitels    |✅ Ja           |
|Tabel caption   |✅ Ja           |
|Kleuren & layout|❌ Nee (gedeeld)|
|Tabel structuur |❌ Nee (gedeeld)|

### 6.3 WPML String Translation Workflow

Admin gaat naar: **WPML → String Translation → filter op domein “tablemaster-pro”**  
Daar kan hij/zij alle teksten van alle tabellen per taal vertalen.

## 7. Beveiliging

- Alle database queries via `$wpdb->prepare()` — geen SQL injection mogelijk.
- Celinhoud gesanitiseerd via `wp_kses_post()` (HTML toegestaan maar gefilterd).
- Admin-acties beveiligd met WordPress **nonces**.
- Capability-check: alleen gebruikers met `manage_options` (of custom capability `tablemaster_manage`) kunnen tabellen beheren.
- AJAX endpoints controleren nonce én capability voor elke request.
